# Token-2022 rollout — 19 September 2026

Future One Only launches can use Token-2022 with immutable mint metadata. Existing SPL mints and pools retain their current program and continue trading, claiming fees, and graduating using their own on-chain configuration.

Upgrade preparation deployed as `dpl_DeQaQyEcEsa4xhjEazabfHQXtrGz` (`https://oneonly-dvrmrn0te-kade.vercel.app`, production alias `https://app.oneonly.lol`). The release was staged from the prior live deployment with only this upgrade's files overlaid, excluding unrelated concurrent admin work.

## Owner approval and activation

1. Open https://app.oneonly.lol/app/setup with the platform owner wallet.
2. Review and approve one replacement configuration for each of SOL, USDC, JUP, MET, SPYX, QQQX, NVDAX, TSLAX, and CRCLX. Each spends account rent and a network fee in SOL. The app never holds the owner's signing key.
3. Collect each confirmed config address from the transaction review/history. Verify the account on mainnet: Token-2022 base type, correct quote mint, immutable authority, published supply/fees/locks, owner fee/leftover receivers, and unchanged curve/threshold.
4. Set each verified address in production as `DBC_CONFIG_TOKEN2022_<SYMBOL>` and redeploy. These variables take precedence over `DBC_CONFIG_<SYMBOL>`. Before activation, existing legacy configurations remain selected for launches. Keep the legacy variables for rollback; reverting selection affects future launches only.
5. Confirm the setup page marks all nine Token-2022 configurations active and perform an owner-approved launch when desired. No mainnet launch or purchase was executed as part of this verification.

Setup intents use `setup-token2022-<SYMBOL>`, distinct from the previous setup. Confirmed intents can be reopened without creating another configuration. The server rejects replacement configurations whose starting price, liquidity curve or graduation threshold would differ from the current configuration. Launch validation checks that the selected config actually uses the expected token program.
